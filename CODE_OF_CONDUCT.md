# Code of conduct

This is a personal project with one maintainer. These are the ground rules for anyone who takes part in it.

## Expected behavior

- Be respectful. Disagree with the work, not the person.
- Be specific and constructive in reviews and comments.
- Assume good faith, and ask when something is unclear.
- Accept that the maintainer has the final say on what goes into the project.

## Unacceptable behavior

- Insults, personal attacks, or harassment of any kind.
- Discriminatory language or jokes.
- Publishing someone else's private information.
- Spam, off-topic promotion, or repeated demands for attention.
- Anything else that would be out of place in a professional working relationship.

## Scope

These rules apply to issues, pull requests, discussions, and any other space set up for this project. They also apply when you speak for the project in public.

## Enforcement

Report problems by email to ajerofranklin_dev@proton.me. Include links or screenshots if you have them.

This is a solo project. There is no committee or review board. The maintainer reads every report, decides what to do, and keeps reports private where possible. If the report is about the maintainer, there is nobody else to take it. In that case, use GitHub's own reporting tools.

## Consequences

The maintainer may do any of the following, depending on how serious the behavior is:

1. Ask you to stop or edit a comment.
2. Hide or delete a comment, issue, or pull request.
3. Block you from the repository for a period of time or permanently.
